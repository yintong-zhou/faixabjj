# Directives

SOP (Standard Operating Procedure) in Markdown — Livello 1 dell'architettura descritta in [`AGENT.md`](../AGENT.md).

Ogni direttiva definisce: obiettivo, input, tool/script di `execution/` da usare, output atteso, casi limite. Vengono aggiornate nel tempo man mano che si scoprono vincoli, errori comuni o approcci migliori — non vanno create o sovrascritte senza che sia esplicitamente richiesto.

Ancora vuota: nessuna direttiva è stata definita per questo progetto.
